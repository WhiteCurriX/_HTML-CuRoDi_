# Tarea de Evaluación Práctica — UD1: Introducción a los Lenguajes de Marcas

## 📋 Descripción

Este README describe la tarea de evaluación práctica correspondiente a la **Unidad Didáctica 1 (UD1)** del módulo de **Lenguaje de Marcas**, centrada en los conceptos fundamentales de los lenguajes de marcado (HTML/XML) y su estructura básica.

> ⚠️ **Nota:** este documento es una plantilla genérica. Si tienes el enunciado original de tu profesor/a (PDF, Word, etc.), compártelo y adapto el contenido exacto (objetivos, criterios, ponderación) al enunciado real.

## 🎯 Objetivos de la UD1

- Comprender qué es un lenguaje de marcas y para qué se utiliza.
- Diferenciar entre lenguajes de marcas de presentación, estructura y datos (HTML, XML, etc.).
- Conocer la sintaxis básica: etiquetas, atributos, elementos, anidamiento.
- Crear un documento válido y bien formado siguiendo las reglas del lenguaje.
- Utilizar herramientas de validación (W3C Validator u otras) para comprobar la corrección del documento.

## 📝 Enunciado de la tarea

Se propone la creación de un documento (HTML o XML, según corresponda) que cumpla los siguientes requisitos:

1. Estructura básica correcta (declaración de tipo de documento, etiquetas raíz, codificación de caracteres).
2. Uso correcto de etiquetas y atributos según la sintaxis del lenguaje.
3. Anidamiento y cierre correcto de todas las etiquetas.
4. Inclusión de al menos:
   - Una estructura jerárquica (listas, tablas o árbol de elementos).
   - Metadatos básicos (título, autor, codificación).
5. Documento validado sin errores (adjuntar captura o informe de validación).

## 🛠️ Requisitos técnicos

- Editor de texto o IDE (VS Code, Notepad++, etc.).
- Navegador web actualizado para comprobar el resultado.
- Validador en línea (por ejemplo, el validador de marcado del W3C).

## ✅ Criterios de evaluación

| Criterio | Peso |
|---|---|
| Estructura y sintaxis correctas | 30% |
| Validación sin errores | 20% |
| Uso adecuado de etiquetas/atributos | 20% |
| Organización y legibilidad del código | 15% |
| Presentación y entrega en plazo | 15% |
